## 6.1 Seus direitos pela LGPD {#seus-direitos-pela-lgpd}

| Direito | O que significa |
| Confirmação e acesso | Saber se tratamos seus dados e receber uma cópia |
| Correção | Corrigir dados incompletos, errados ou desatualizados |
| Anonimização, bloqueio ou eliminação | Para dados desnecessários, excessivos ou tratados em desacordo com a lei |
| Portabilidade | Receber seus dados para levar a outro fornecedor, quando cabível |
| Eliminação dos dados tratados com consentimento | Apagar o que dependia do seu aceite |
| Informação sobre compartilhamento | Saber com quem compartilhamos seus dados |
| Informação sobre o consentimento | Saber o que acontece se você não consentir |
| Revogação do consentimento | Retirar o aceite a qualquer momento |
| Oposição | Opor-se a um tratamento feito sem consentimento, se ele descumprir a lei |
| Revisão | Pedir revisão de decisões tomadas só por meio automatizado |

## 6.2 Como fazer uma solicitação {#como-fazer-uma-solicitacao}

- Acesse a página de solicitação de privacidade ou escreva para contato@tipe.digital.
- Diga o que deseja e se você é cliente de restaurante, restaurante, colaborador ou outro.
- Para clientes na mesa, informe também o restaurante, a data e o valor aproximado do pagamento. Como não pedimos e-mail na mesa, esses dados nos ajudam a localizar o registro.
- Podemos pedir uma confirmação de identidade antes de responder, para proteger seus dados. Nunca pedimos senha.

O atendimento é gratuito.

## 6.3 Prazos {#prazos}

A confirmação de existência ou o acesso em formato simplificado são respondidos imediatamente, sempre que possível. A declaração completa é enviada em até 15 dias, contados do pedido.

## 6.4 Quando o pedido vai para o restaurante {#quando-o-pedido-vai-para-o-restaurante}

Para dados da conta da mesa, o controlador é o restaurante. Nesses casos, encaminhamos o seu pedido a ele, avisamos você e ajudamos no atendimento. Alguns dados podem ser mantidos mesmo após um pedido de exclusão, quando houver obrigação legal ou fiscal, prevenção a fraudes ou defesa em processos (Livro 3, seção 3.13).
